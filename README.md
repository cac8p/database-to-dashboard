# Database to Dashboard: Ridgeline Intelligence

An end-to-end analytics engineering project. It takes raw, messy data from a fictional SaaS company's source systems and builds it into a tested, documented warehouse using a **medallion architecture** (bronze → silver → gold) that feeds an executive **Power BI** dashboard.

> **Ridgeline Intelligence is a fictional company.** All data is synthetic, generated by `generator/generate_saas_data.py`. No real customer or employer data is used.

## Architecture

```
 SOURCE SYSTEMS              BRONZE (raw)          SILVER (clean)          GOLD (business-ready)      BI
 ───────────────             ─────────────         ──────────────          ─────────────────────      ──
 CRM (accounts, reps)   ──►  loaded as-is     ──►  typed, deduped,    ──►  dim_account, dim_product ──► Power BI
 Billing (subs, invoices)    + load metadata       standardized,           fct_subscriptions,          dashboard
 Product app (users,         (never edited)        conformed keys          fct_usage_weekly,
   usage event logs)                                                       mart_arr_monthly,
 Reference (FX rates)                                                      mart_churn_cohorts
```

| Layer | Tool | Status |
|---|---|---|
| Source data | Python generator (pandas, Faker) | ✅ Done |
| Database | DuckDB (local), then Snowflake | ⏳ Next |
| Transformations + tests | dbt | ⏳ |
| Dashboard | Power BI | ⏳ |
| Second source | SEC EDGAR + FRED public APIs | ⏳ |

## The fictional business

Ridgeline sells market-intelligence subscriptions to banks, asset managers, insurers and corporates across North America, EMEA, APAC and LATAM. Six products range from a research portal to a pricing-benchmark API. The simulation includes:

- Annual and multi-year contracts that **renew, expand, contract or churn**, driven by a hidden account health score
- **Usage declines before churn**, so leading indicators can be detected
- A **6% price increase** (Jan 2025), a **new product launch** (May 2024) and **Q4 sales seasonality**
- Multi-currency billing (USD, GBP, EUR)

Raw data is intentionally messy (duplicate CRM records, a billing-system migration that changes formats, schema drift in event logs, late-arriving events and more) so the silver layer has real cleanup to do.

## Run it yourself

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows  (Mac/Linux: source .venv/bin/activate)
pip install -r requirements.txt
python generator/generate_saas_data.py
```

That creates about 2,000 accounts, 25,000 users, 4,500 subscriptions, 7,400 invoices and 390,000 usage events covering Jan 2023 to Oct 2026. The same seed always produces the same data.
